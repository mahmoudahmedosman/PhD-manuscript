\section{Testing NaCl on Real Data} \label{sec:nacl_real_data}

An important part of this work is to validate the NaCl framework on observational data. We therefore apply the model to the SNfactory (\cite{snfactory}) 
dataset, which provides a particularly well-suited test case for a spectrophotometric model. The SNfactory program obtained time-series 
spectroscopy of Type Ia supernovae with the SNIFS instrument, providing a densely sampled spectrophotometric dataset for individual 
supernovae. The accurate spectrophotometric calibration of the SNIFS observations allows the spectra to provide an absolute measurement of the flux, 
reducing the need for separate photometric measurements. 

The SNfactory dataset is also particularly relevant in the context of NaCl because it has been used to develop several empirical models that 
aim to describe supernova diversity beyond the standard SALT2 parameterization. These include SNEMO 
(\cite{Saunders_2018_SNEMO}), SUGAR (\cite{L_get_2020_SUGAR}), Twins Embedding (\cite{Boone_2021_twins_embedding}), and SuPAErnova 
(\cite{Stein_2022_PAE}). The use of SNfactory data in these studies motivates its use here as a test case for NaCl, while also providing a 
natural framework for future extensions of the model to alternative parameterizations.

In this work, however, we retain the SALT2 parameterization. The objective at this stage is to assess the 
ability of NaCl to model real spectrophotometric data within a well-established parameterization. 
We present here the results obtained by training NaCl on the SNfactory dataset using this SALT2 
parameterization.

\subsection{Implementing a Model for Spectrophotometric Data}


For the SNfactory dataset, NaCl must directly model the spectrophotometric 
observations rather than combining independently measured photometric and 
spectroscopic data. The model is therefore trained directly on the 
flux-calibrated spectra obtained at different phases of each supernova. 
This requires adapting the model prediction and likelihood to the 
spectrophotometric data format, so that the predicted spectra can be 
compared directly to the observations.


For spectrophotometric data, both the spectral shape and the 
normalization are determined simultaneously from the same observation. 
The predicted spectral flux is then given by:
\begin{equation}
    f_{\text{spectrophotometric}}((1+z)\lambda, (1+z)p) = X_0 \frac{1}{1+z} [M_0(\lambda,p) + X_1M_1(\lambda, p)] \times 10^{0.4c CL(\lambda)}
\end{equation}
expressed in $\text{erg}/\text{cm}^{2}/\text{s} / \AA$. 
This formulation removes the need for a spectral recalibration 
polynomial $SpecRecal(\lambda)$ and reintroduces the colour law 
$CL(\lambda)$, which is now constrained directly from the spectra. 
The model derivatives have also been adjusted to enable model evaluation and log-likelihood minimization. 
The results on the data are presented in the following section.

\subsubsection{Training Residuals}

We would like to examine how well a SALT2-like parameterized model is able to describe the spectrophotometric evolution of supernovae. 
In order to do that, we will be looking at the weighted training residuals of the model on the entirety of the data and check if there are any particular features that stand out. 
This is presented in Figure \ref{fig:snf_pulls} where we have calculated the weighted training residuals which indicate by how many standard deviations ($\sigma$) our model differs from the data, 
also known as pulls. We do that for each data point and stack them on top of each other if they have been observed at the same time. So for example if we have 2 spectra 
measured at phase of $p= -1$ with data points at $5000{\AA}$, it will ll appear as one point on the figure and its value will be the average of the 2 pulls. We then get a 
figure that represents the accuracy of the model in the $\lambda-p$ space. This also means that each horizontal line represents on average how well a spectrum is modeled 
at that particular rest-frame phases, while the vertical lines are for specific rest-frame wavelengths. \\

\noindent We see in Figure \ref{fig:snf_pulls} that for most of the $\lambda-p$ space the training residuals show good agreement between the model and the data. 
But what also stands out is that we can identify three distinct wavelength regions where the model is unable to capture the variability of the data. 
These three regions are found at $\sim 3500 {\AA}$, $\sim 6000 {\AA}$ and $\sim 8000 {\AA}$, which correspond to UV, Si II and Ca II. These are known to 
have very diverse forms (\cite{Wang_2012_UV}, \cite{Parrent_2016_Si_II}) and we can see here that they are not captured by a SALT2 parameterization. 
It is important to mention that the models mentioned in Chapter 2 that go beyond the SALT2 parameterization can capture this additional variability with the help of extra parameters.
