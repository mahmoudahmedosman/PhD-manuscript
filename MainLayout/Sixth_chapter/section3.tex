\section{Applications on Uchuu-ZTF Mocks}

\subsection{Uchuu-ZTF Mocks} \label{sec:uchuu_ztf}

The ZTF simulations are designed to test the impact of ZTF-supernovae peculiar velocities in a cosmological analysis are called DC PV (Data Challenge 
Peculiar Velocity). These are generated within the ZTF collaboration mainly to test the methods to infer $f\sigma_8$. 
The DC PV simulations are done similarly to the DC simulations  
described in Chapter 4 with the main differences being that supernovae are simulated on top of large scale structures instead of a uniform distribution. 
For that, we use the Uchuu N-body simulation 
(\cite{Ishiyama_2021}), a high fidelity N-body dark matter simulation\footnote{N-body and hydrodynamical simulations 
are considered the highest fidelity simulations we can get to describe structure formation as they solving the equations of motion for each particle/fluid without any 
approximations or grid mesh} 
in a $(2 \text{Gpc}.h^{-1})^3$ box with 2.1 trillion particles that can be seen in Figure \ref{fig:uchuu_nbody} . 
The full box is then subdivided into 27 subboxes where the supernovae are simulated up to a redshift of $z=0.11$, giving 27 quasi-independent 
realizations of the DC PV. 
Each supernova is simulated at the location of a dark matter halo is and is assigned the halo's velocity. This allows us to add proper motion to supernovae 
that is driven by structure formation.\\

\begin{figure}[ht]
    \centering
    \includegraphics[width=0.7\textwidth]{MainLayout/BORG_chapter/figures/uchuu_nbody.png}
    \caption{Slice taken from the Uchuu simulation covering a box of 250 $\text{Mpc}.h^{-1}$ where each point represents a particle. Taken from \cite{Ishiyama_2021}}
    \label{fig:uchuu_nbody}
\end{figure}


We opt to simplify a few aspects of the simulations in order to have an initial assessment of how well can a BORG analysis run on ZTF-like supernova. 
Firstly, we have chosen to use only the distance moduli and redshifts of supernovae as inputs in BORG, as if we were doing the analysis after having run the full 
LEMAITRE pipeline. 
One could also infer the Tripp relation parameters ($\alpha_{\text{Tripp}}$, $\beta_{\text{Tripp}}$) in BORG. 
Performing this inference at the BORG level would offer an 
additional advantage: the 3-dimensional reconstruction of the matter 
distribution in the nearby Universe provides a 
correction for inhomogeneous Malmquist bias. In standard analyses, 
Malmquist bias corrections rely on an assumed homogeneous distribution 
of matter, which can introduce systematic errors in underdense and 
overdense regions. Within BORG, the reconstructed density field 
directly encodes the inhomogeneous matter distribution along each line 
of sight, allowing a more accurate correction for the preferential 
detection of supernovae in overdense environments near the survey 
boundary.
Secondly, we do not impose the ZTF DR2 cosmology quality cuts on photometry nor the ZTF footprint, so all of the supernovae that are 
generated can be used. 
For a more realistic set of simulations, we would have to account for the geometry of the survey as well as the Milky-Way dust. This is trivial to account for, but 
for simplicity we opted not to include it. 
It consists in introducing an 
angular mask $M(\text{RA}, \text{Dec})$ in the likelihood's selection function. 
This method was applied in BORG analyses such as 
\cite{Mcalpine_2025} (Manticore-Local) and \cite{Mcalpine_2026} (Manticore-Deep). 
Finally, we simulate ZTF-like supernova up to a redshift of $z=0.11$ and draw a set of 1000 randomly selected supernovae whose observed redshift goes up to $z=0.06$ in order to 
match the expected number of supernovae in the volume-limited sample from ZTF. \\

\subsection{Forward Model Analysis: Likelihood Test}

The methodology used to generate supernova in the self consistent simulations and Uchuu-ZTF mocks are different as 
we have mentioned earlier. We want to ensure that we can 
quantify any systematic biases introduced by those differences and to have an intial guess of the model parameters that is close to the truth when running the full inference. 
To do this, we start by generating an initial density field with BORG $\delta^{\text{BORG}}_{IC}$ using the 
Planck18 cosmological parameters (\cite{Planck_2018_params}) and known bulk flow $\mathbf{V}$. 
The configuration of the generated field is given in Table \ref{tab:borg_nbody}. 
We then let that field evolve using COLA gravity model to obtain the evolved density field 
$\delta^{\text{BORG}}_{F}$ and velocity field $\mathbf{v}^{\text{BORG}}_{IC}$. The ZTF simulations are designed to generate the supernovae on top of an N-body simulation, so 
from the evolved density field we create a "synthetic" N-body simulation. We use COLA to have the most accurate version of this synthetic N-body simulation. 
The simplest way to do so is to take each voxel-$i$ and generate within it $N_i$ particles proportional 
to $(1+\lceil \delta^{\text{BORG}}_{F}\rceil )_i$ where $i$ denotes the voxel index.
 We take the ceiling of the evolved density field to ensure we get an integer number of 
particles and to have at least 1 particle in empty voxels. We also generate fewer particles than in the Uchuu simulation, 
around 2 million, due to memory and storage limiations. \\

We then use this "synthetic" N-body simulation to generate ZTF-like supernovae using skysurvey (\cite{Rigault_2026}) and then evaluate the BORG-supernova likelihood (Equation \ref{eqn:borg_pv_L}) 
while varying the cosmological and model parameters in BORG. We create a likelihood profile for each parameter, not only to 
determine whether the Uchuu-ZTF-like supernova simulations introduce systematic biases in BORG but also to help us understand how we can relate some of the BORG-supernova model 
parameters, 
such as $\alpha$ to the Uchuu-ZTF simulations as they are not explicitly specified. \\

We obtain the following likelihood profiles for one synthetic N-body simulation in Figures \ref{fig:params_coverage_ztf_1} and \ref{fig:params_coverage_ztf_2}. 
We notice that the cosmological parameters $\Omega_m$ and $\sigma_8$ are unbiased and we recover the 
input cosmology. The bulk flow $V$ parameters are compatible with 0 km/s within the standard deviation, 
indicating that no additional bulk flow is added within the ZTF simulation. 
The bias model parameter $\alpha$ 
seems to prefer values around $\sim 0.8$. Intuitively, we expect $\alpha$ to be closer to 1 since the supernovae are most likely simulated on top of the particles.  
The velocity dispersion is preferred around $200$ km/s. 
The $\mu_A$ parameter seem to prefer a value of $1.0$, meaning no additional sources of uncertainty are added to the distance modulus.

\subsection{Inference Results on the Uchuu-ZTF Simulation}
We present in this section the results obtained on the DC PV. The procedure follows closely what was done on the self consistent simulations. 
The priors set on the parameters are:
\begin{itemize}
    \item $\alpha \sim \mathcal{U}[0.5, \, 2.5]$
    \item $\mu_A \sim \mathcal{U}[0.5, \, 1.5]$
    \item $\sigma_v \sim \mathcal{U}[50, \, 400] \, \text{km.s}^{-1}$
    \item Each bulk flow component $\sim \mathcal{U}[-200, \, +200] \, \text{km.s}^{-1}$ 
    \item $\Omega_m \sim \mathcal{U}[0.1, \, 0.8]$
    \item $\sigma_8 \sim \mathcal{U}[0.1, \, 1.5]$
\end{itemize}

The inference runs in four steps: 
\begin{enumerate}
 \item An initial warm-up phase is dedicated to sample the initial density perturbations $\delta^{IC}$ while all of other parameters are fixed using an LPT gravity solver. 
 This is done in 1000 MCMC steps.
 \item The following step we simultaneously $\delta^{IC}$ alongside nuisance and model parameters, specifically 
 $\sigma_v$, bulk flow, $\alpha$ and $\mu_A$ also using LPT. This is done for 3000 MCMC steps. 
 \item We keep on sampling the same parameters but switch to COLA for the gravity solver. The idea is that since LPT is much faster than COLA, to use it to initially guess some 
 of the model parameters so that sampling the parameters is then easier with COLA. For this run, it was done for 800 MCMC steps. 
 \item Lastly, we sample all of the parameters simultaneously including $\Omega_m$ and $\sigma_8$ using COLA. This step 
 takes a lot of computational on CPU. A converged state would be achieved during the timeline of this PhD. Efforts to parallelize the computations on GPUs is ongoing to accelerate this step.
\end{enumerate}
We can see that now we have an additional step in the inference compared to what was done for the self-consistent simulations. 
This is represented in Figure \ref{fig:dens_ztf_evolution} where we compare the mean density field $\delta^{F}$ within a slice at the center of the 
box when during the phase where the initial 
conditions are sampled wiht LPT described in step 2, and when we switch to COLA, described in steps 3 and 4. 

Figure \ref{fig:stacked_dens_ztf} compares the Uchuu density field with the reconstructed field in different slices near the center of the box. We can immediately notice the 
that the amplitude of the Uchuu field is way larger than the reconstructed field with BORG-PV. The reconstructed field does manage to capture some of the underlying structures 
in the Uchuu field at large scales but at a much lower amplitude. Moreover, looking at the reconstructed velocity field in Figure \ref{fig:stacked_vel_ztf}, we notice 
that the reconstructed field has much smaller velocities than the expected.

\subsection{Model Mismatch}

The previous results on the reconstructed fields indicate that the inference pipeline is not currently capable at reconstructed the underlying matter and velocity fields 
when the supernova are generated from an external source to BORG. This hints at the fact that there are strong model mismatches that introduce biases in the pipeline. 


A possible explanation for these mismatches is related to the bias model. 
The current implementation of the bias model $b_{\text{SN}} = (1+\delta^F)^{\alpha}$ was constructed based on a phenomonological approach and may overly simplify the 
true relation between the positions of supernovae and the overdensities used in Uchuu-ZTF. 
If we were to construct a field of supernova overdensities, the current bias model would effectively impose the relation:
\begin{equation}
    1+\delta_{\text{SN}} = (1+\delta^F)^{\alpha}
\end{equation}
where $\delta_{\text{SN}}$ denotes the supernova overdensities. We can compare this relation from the Uchuu-ZTF simulations to self-consistent simulations with varying values of 
$\alpha$ to see if the current bias model can represent the Uchuu-ZTF supernovae overdensities. We obtain the results in Figure \ref{fig:nsn_vs_dens}. We see that no value of $\alpha$ 
seem to be capable at fully describing the Uchuu-ZTF data. At most, we find certain values of $\alpha$ being able to describe a portion of the relation between overdensities. 
This indicates that we need a more complex bias model to be able to run BORG-PV on the Uchuu-ZTF mock.

\section{Conclusion}

This chapter presented the first application of the BORG pipeline directly to simulated supernova data representative of the ZTF volume-limited dataset.

The results obtained from self-consistent simulations demonstrate the ability of BORG to reconstruct the underlying matter and velocity fields directly from supernova 
distances. The reconstruction successfully recovers the large-scale structure, while small-scale features are less well constrained due to the limited number of supernovae. 
Although the sampling of the model parameters has not yet fully converged, preliminary results indicate that the parameters describing the supernova bias model and velocity 
dispersion are accurately recovered, while the bulk-flow parameters appear to be biased. Likelihood profile tests suggest that this discrepancy may be realization-specific, 
with the bulk flow being sampled around a value different from that of the input realization. Preliminary results from the parameter sampling also indicate that the 
field-level inference does not introduce a significant bias in the growth-rate parameter $f\sigma_8$.

However, the methodology did not achieve the same level of agreement when applied to the more realistic external simulations generated from the Uchuu N-body simulation. 
The discrepancies observed in this case are likely to originate from model mismatches between the simulations and the BORG forward model, with the supernova bias model 
identified as a particularly important source of mismatch.

A primary objective for future work will therefore be to identify and account for these model mismatches in order to enable the application of BORG-PV to external 
simulations. The convergence of the parameter sampling must also be established before drawing definitive conclusions about the parameter inference. Once these issues are 
addressed, the methodology can be extended to more realistic simulations incorporating the survey footprint and a redshift-dependent supernova rate. An additional challenge 
will be to account for correlations between supernova distance measurements. As shown in Chapter \ref{chap4}, correlations between the supernova light-curve parameters 
propagate into the distance moduli produced by EDRIS and therefore need to be incorporated into the likelihood. Properly accounting for these correlations will be 
essential for applying the methodology to realistic observational data.
